# Avalanche Rush · 极地逃亡

一款原创的 2D 横版雪崩滑雪冒险游戏。玩家需要在不断逼近的雪崩前保持速度，完成空翻与完美落地，收集物资，并借助动物伙伴和雪地摩托突破障碍。

> 当前版本为可直接游玩的 HTML5 Canvas MVP，不依赖外部游戏引擎或美术资源。

## 已实现功能

- 动态坡度滑行、俯身加速、跳跃、空翻与落地判定
- 持续追赶并逐渐提速的雪崩系统
- 程序化雪山地形和阶段难度增长
- 树木、岩石、跳台和物资等随机内容
- 雪橇犬、企鹅两种伙伴
- 临时雪地摩托载具，可撞碎障碍
- 分数、距离、连击、最佳纪录与结算
- 键盘、鼠标和触摸操作
- 响应式界面、动态合成音效和 PWA 离线缓存
- GitHub Pages 自动部署工作流

## 操作方式

| 输入 | 行为 |
| --- | --- |
| 按住 `Space` / `S` / `↓` / 屏幕 | 俯身加速；空中向前旋转 |
| 松开按键或屏幕 | 在地面起跳 |
| `P` / `Esc` | 暂停或继续 |
| `Enter` | 从菜单开始或快速重开 |

### 落地技巧

角色落地时，滑雪板方向越接近雪坡切线，落地评价越高。完整空翻并完美落地会提高连击倍率，同时获得短暂冲刺。

## 本地运行

项目是纯静态网页。为了正常加载 ES Module 和 Service Worker，请使用本地 HTTP 服务：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

也可以使用：

```bash
npx serve .
```

## 技术说明

- Canvas 使用固定逻辑分辨率 `1280 × 720`，再适配实际设备像素比。
- 物理以 120 Hz 固定时间步更新，降低不同刷新率下的手感差异。
- 地形采用多层正弦函数生成，并通过线性插值计算实时高度和坡度。
- 玩家保持在屏幕左侧稳定区域，世界和镜头持续向前推进。
- 所有角色、障碍、粒子和背景均由 Canvas API 绘制，不包含第三方素材。
